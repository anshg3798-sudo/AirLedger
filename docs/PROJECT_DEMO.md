# Project demo

1. Start both services using the setup guide. Open Dashboard and point out the observed AQI average, 60-day trend and historical budget count.
2. Open Predict AQI and choose Winter. Submit to show the category, probability bars, overshoot and ranked actions. Load Summer and Monsoon to compare outcomes.
3. Clear a pollutant field and submit. Show the field-specific error and restore the preset.
4. Open 7-Day Forecast and run the baseline simulation. Count seven successive dates and explain why repeated runs may differ.
5. Open Model Insights. Compare training CV selection with the 219-record holdout, explain the confusion matrix and point to standardized coefficients.
6. Run the test commands locally. Once GitHub is connected, open the Actions jobs and trace the training, tests and build.
