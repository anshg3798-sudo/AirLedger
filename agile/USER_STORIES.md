# User stories

- **AL-1** As an analyst, I want a clean dataset and baseline models so that AQI can be predicted reliably.
- **AL-2** As a user, I want to enter environmental conditions and receive predicted AQI and a risk classification instantly.
- **AL-3** As an official, I want to see pollution-budget overshoot and recommended actions so that I can respond proportionately.
- **AL-4** As a planner, I want pollution trends and a short-term outlook so that I can understand environmental patterns.
- **AL-5** As a data scientist, I want to inspect model performance so that I can evaluate prediction quality.
